# Retail Sales & Profitability Intelligence

An interactive Tableau dashboard analyzing retail sales, profitability, and business performance using the Sample Superstore dataset.

## Project Overview

This project explores retail business performance through interactive visualizations and KPIs built in Tableau Public.

The dashboard helps users understand sales performance, profit, profit margin, order volume, and category-level sales across different regions.

## Business Questions

- What is the total sales revenue?
- How much profit does the business generate?
- What is the overall profit margin?
- How many orders were placed?
- Which product categories generate the highest sales?
- How do sales vary across regions?
- How can interactive filters support business analysis?

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Profit Margin KPI
- Total Orders KPI
- Sales by Category chart
- Category filter
- Region filter
- Interactive Tableau dashboard

## Tools & Technologies

- Tableau Public
- Microsoft Excel
- Data Visualization
- Business Intelligence
- Exploratory Data Analysis

## Dataset

Sample Superstore dataset.

The dataset contains retail orders, customers, products, sales, profit, categories, and regional information.
